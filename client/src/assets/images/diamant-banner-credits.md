# Sources des affiches de la bannière DIAMANT

Les trois affiches publicitaires ont été générées à partir des images sources ci-dessous, en conservant les diamants comme sujets et en ajoutant des personnages 3D. Les images originales restent enregistrées séparément.

- `diamant-banner-poster-asscher.jpg` — affiche générée à partir de `diamant-banner-asscher-cut.png` (AmberLocket, CC0 1.0). Source : https://commons.wikimedia.org/wiki/File:Asscher_cut_diamond_7.png
- `diamant-banner-poster-rough.jpg` — affiche générée à partir de `diamant-banner-rough-diamonds.jpg` (Jerry Cone, domaine public). Source : https://commons.wikimedia.org/wiki/File:Diamond-1128734.jpg
- `diamant-banner-poster-smithsonian.jpg` — affiche générée à partir de `diamant-banner-smithsonian-diamonds.jpg` (Smithsonian Institution, domaine public). Source : https://commons.wikimedia.org/wiki/File:Colorado_Diamond_Crystal,_Freedom_Diamond,_Uncle_Sam_Diamond,_Canary_Diamond.jpg
