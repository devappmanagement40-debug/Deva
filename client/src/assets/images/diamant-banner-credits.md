# Sources des affiches de la bannière DIAMANT

Les cinq affiches publicitaires montrent des personnages stylisés en 3D avec les diamants comme sujets. Elles ont été générées à partir des images de référence ci-dessous. Les PNG haute résolution générés sont conservés dans `attached_assets/generated_images/`; les JPEG optimisés correspondants sont utilisés dans le carrousel.

- `diamant-poster-3d-01-asscher.jpg` et `diamant-poster-3d-04-asscher-presenter.jpg` — affiches générées avec le diamant Asscher de `diamant-banner-asscher-cut.png` (AmberLocket, CC0 1.0). Source : https://commons.wikimedia.org/wiki/File:Asscher_cut_diamond_7.png
- `diamant-poster-3d-02-rough.jpg` — affiche générée avec les diamants bruts de `diamant-banner-rough-diamonds.jpg` (Jerry Cone, domaine public). Source : https://commons.wikimedia.org/wiki/File:Diamond-1128734.jpg
- `diamant-poster-3d-03-collection.jpg` et `diamant-poster-3d-05-gem-showcase.jpg` — affiches générées avec la collection de diamants de `diamant-banner-smithsonian-diamonds.jpg` (Smithsonian Institution, domaine public). Source : https://commons.wikimedia.org/wiki/File:Colorado_Diamond_Crystal,_Freedom_Diamond,_Uncle_Sam_Diamond,_Canary_Diamond.jpg

Les deux photos d'équipe ci-dessous ont été fournies par l'utilisateur. Elles restent des photographies réelles, sans génération 3D; seules des copies JPEG réduites et compressées sont utilisées dans le carrousel.
