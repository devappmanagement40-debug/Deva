---
name: DIAMANT URL-only scope
description: Preserve all non-URL behavior when changing page routes or referral links.
---

For URL and routing work, change only route definitions, URL generation, and compatibility handling. Do not alter page design, business rules, page content, or stored data unless the user separately requests those changes.

**Why:** The user explicitly limited the requested change to URLs and said not to modify anything else on the site.

**How to apply:** Keep URL-only requests isolated to routing and link generation; verify the existing interface and behavior remain unchanged.
