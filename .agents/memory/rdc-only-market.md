Registration and login allow only Côte d’Ivoire (CI) and Togo (TG), with CI as the default. The user requested that existing accounts assigned to other countries be moved to CI; preserve their phone, password, and historical records. This restriction is specific to authentication: keep country configuration for other app features admin-managed and do not remove their payment/operator data. Product prices and product earnings are entered directly as XOF and displayed as XOF without conversion. Team/referral summaries, member totals, and other visible amount labels throughout the site use XOF without conversion; stored numbers and transaction logic remain unchanged. On the « Moi » profile card only, the raw balance number is labeled FCFA without conversion. The deposit page offers Mobile Money through active, admin-configured operators for the user's country and USDT BEP20; do not hardcode country/operator lists. New crypto deposits accept only USDT BEP20, while existing deposit history and settlements remain intact. Withdrawals offer USDT BEP20 and active Mobile Money operator names configured for the user's country; do not expose deposit receiving numbers as withdrawal destinations.

**Why:** the user changed the authentication-market rule to CI/Togo and asked that existing out-of-market accounts move to CI. The earlier global country/payment behavior still applies outside the authentication pages. The user also requires XOF display labels without conversion, FCFA only on the « Moi » balance, USDT BEP20 for crypto deposits/withdrawals, and Mobile Money operators from country configuration.

**How to apply:** enforce CI/TG in both authentication UI and server validation, default to CI, and normalize remembered auth countries outside that list to CI. Keep non-auth country configuration and active payment operators admin-managed. Show visible monetary amounts with XOF using stored numeric values unchanged. Apply FCFA only to the « Moi » profile display; never change calculations, storage, provider amounts, payment methods, or network identifiers for a display-label request. For deposits and Mobile Money withdrawals, load active operators from the user's configured country; only withdrawals via USDT BEP20 use NOWPayments, and historical records remain intact.
