---
name: Global country selection
description: Country selection behavior, default phone country, and monetary display rules.
---

Registration lists only active countries from the admin-managed country table. Login lists all configured countries, including inactive ones, so existing accounts can still sign in after deactivation. Country names, codes, and phone prefixes are not restricted by a fixed authentication allowlist. Reject registration server-side for inactive countries. Do not delete a country while accounts, payment records, wallets, deposit channels, or receiving numbers still reference it; deactivate it instead. Product prices and product earnings are entered directly as XOF and displayed as XOF without conversion. Team/referral summaries, member totals, and other visible amount labels throughout the site use XOF without conversion; stored numbers and transaction logic remain unchanged. On the « Moi » profile card only, the raw balance number is labeled FCFA without conversion. The deposit page offers Mobile Money through active, admin-configured operators for the user's country and USDT BEP20; do not hardcode country/operator lists. New crypto deposits accept only USDT BEP20, while existing deposit history and settlements remain intact. Withdrawals offer USDT BEP20 and active Mobile Money operator names configured for the user's country; do not expose deposit receiving numbers as withdrawal destinations.

**Why:** the user clarified that country activation in administration controls registration and login choices, while accounts from deactivated countries must remain able to sign in. The user also requires XOF display labels without conversion, FCFA only on the « Moi » balance, USDT BEP20 for crypto deposits/withdrawals, and Mobile Money operators from country configuration.

**How to apply:** load active countries for registration and all retained countries for login; enforce the active-country registration rule on the server. Keep names, phone prefixes, and operator lists database-driven. Refuse deletion while stored records reference a country. Show visible monetary amounts with XOF using stored numeric values unchanged. Apply FCFA only to the « Moi » profile display; never change calculations, storage, provider amounts, payment methods, or network identifiers for a display-label request. For deposits and Mobile Money withdrawals, load active operators from the user's configured country; only withdrawals via USDT BEP20 use NOWPayments, and historical records remain intact.
