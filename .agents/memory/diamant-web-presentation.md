---
name: DIAMANT web presentation
description: Approved browser presentation and boundaries for PWA changes.
---

Keep the site in its existing conventional web presentation. Do not add or expand app-like mobile-shell behavior or PWA behavior without approval.

**Why:** The user wants the site to remain a classic website and asked that brand updates not change unrelated presentation behavior.

**How to apply:** Keep rebranding changes to visible identity and metadata; preserve existing responsive layout, service-worker behavior, and standalone configuration unless the user requests a separate change.
