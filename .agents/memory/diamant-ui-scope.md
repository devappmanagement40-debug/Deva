---
name: DIAMANT interface scope
description: Keep existing page design and structure unchanged unless a visual change is requested.
---

For DIAMANT work, do not redesign or otherwise change pages when the request is about behavior or logic. Add only the controls required for the feature and preserve the existing layout and styling.

**Why:** The user repeatedly emphasizes that unrelated page and interface changes are not wanted.

**How to apply:** When a feature needs a new control, place it within the existing component and keep the surrounding pages unchanged.
